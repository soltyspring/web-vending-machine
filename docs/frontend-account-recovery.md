# 프론트엔드 작업 지시서: 계정 찾기 및 비밀번호 재설정

## 목적

로그인 페이지에서 아이디 찾기, 이메일 찾기, 비밀번호 재설정 기능을 사용할 수 있게 만든다.
사용자는 같은 모달 또는 페이지 안에서 입력, 인증코드 발송, 인증, 결과 확인, 비밀번호 재설정을 단계적으로 수행할 수 있어야 한다.

## 화면 구조

로그인 페이지에서 계정 찾기 진입 버튼을 제공한다.

권장 구조:

```text
FindAccountModal
- 아이디 찾기 탭
- 이메일 찾기 탭
- 비밀번호 재설정 탭
```

## 공통 UI 정책

- API 요청 중에는 버튼을 disabled 처리한다.
- 요청 중 버튼 문구를 상황에 맞게 변경한다.
- 예: `확인 중...`, `발송 중...`, `인증 중...`, `재설정 중...`
- 백엔드에서 내려주는 `message`를 우선 표시한다.
- 프론트 자체 검증 메시지도 백엔드 메시지와 동일한 문구를 사용한다.
- 이전 단계 입력값이 바뀌면 이후 단계 인증 상태와 결과를 초기화한다.
- 인증 성공 후에는 인증에 사용한 이메일을 잠그거나, 수정 시 인증 상태를 초기화한다.

## 공통 메시지

프론트엔드와 백엔드는 같은 메시지를 사용한다.

```text
아이디를 찾았습니다.
이메일을 찾았습니다.
인증코드를 이메일로 발송했습니다.
인증이 완료되었습니다.
비밀번호가 재설정되었습니다.
가입된 계정을 찾을 수 없습니다.
이메일 형식이 올바르지 않습니다.
인증코드가 올바르지 않습니다.
인증코드가 만료되었습니다.
새 비밀번호 형식이 올바르지 않습니다.
잠시 후 다시 시도해 주세요.
```

## 에러 표시 위치

모든 에러를 버튼 위에 몰아서 보여주지 않는다.

- 이메일 오류는 이메일 입력창 아래에 표시한다.
- 아이디 오류는 아이디 입력창 아래에 표시한다.
- 인증코드 오류는 인증코드 입력창 아래에 표시한다.
- 비밀번호 오류는 비밀번호 입력창 아래에 표시한다.
- 비밀번호 확인 오류는 비밀번호 확인 입력창 아래에 표시한다.
- 서버 공통 오류는 해당 단계 영역 하단에 표시한다.

## 입력 검증

### 이메일

- 비어 있으면 이메일 입력창 아래에 안내한다.
- 이메일 형식이 틀리면 API 호출 전에 `"이메일 형식이 올바르지 않습니다."`를 표시한다.

### 아이디

- 비어 있으면 아이디 입력창 아래에 안내한다.

### 인증코드

- 비어 있으면 인증코드 입력창 아래에 안내한다.

### 새 비밀번호

- 회원가입과 동일한 비밀번호 정책을 적용한다.
- 새 비밀번호 형식이 틀리면 `"새 비밀번호 형식이 올바르지 않습니다."`를 표시한다.
- 새 비밀번호와 새 비밀번호 확인이 일치하지 않으면 비밀번호 확인 입력창 아래에 안내한다.

## 탭 1: 아이디 찾기

### 화면 흐름

```text
이메일 입력
-> 아이디 찾기 버튼 클릭
-> 마스킹된 아이디 표시
-> 이메일 인증코드 받기
-> 인증코드 입력
-> 인증하기
-> 전체 아이디 표시
```

### 1단계: 이메일로 아이디 일부 찾기

입력 필드:

```text
이메일
```

버튼:

```text
아이디 찾기
```

호출 API:

```http
POST /api/auth/find-username
```

Request:

```json
{
  "email": "user@example.com"
}
```

성공 시 표시:

```text
가입된 아이디: abcde**
```

### 2단계: 전체 아이디 확인용 인증코드 발송

마스킹된 아이디가 표시된 뒤 같은 화면에 인증 영역을 보여준다.

버튼:

```text
이메일로 인증코드 받기
```

호출 API:

```http
POST /api/auth/send-find-username-code
```

Request:

```json
{
  "email": "user@example.com"
}
```

성공 시 표시:

```text
인증코드를 이메일로 발송했습니다.
```

### 3단계: 인증코드 확인 후 전체 아이디 표시

입력 필드:

```text
인증코드
```

버튼:

```text
인증하기
```

호출 API:

```http
POST /api/auth/verify-find-username-code
```

Request:

```json
{
  "email": "user@example.com",
  "code": "123456"
}
```

성공 시 표시:

```text
전체 아이디: abcdefg
```

## 탭 2: 이메일 찾기

### 화면 흐름

```text
아이디 입력
-> 이메일 찾기 버튼 클릭
-> 마스킹된 이메일 표시
```

입력 필드:

```text
아이디
```

버튼:

```text
이메일 찾기
```

호출 API:

```http
POST /api/auth/find-email
```

Request:

```json
{
  "username": "abcdefg"
}
```

성공 시 표시:

```text
가입된 이메일: abcde**@gmail.com
```

주의사항:

- 이메일 찾기는 인증 없이 마스킹된 이메일만 보여준다.
- 이메일 도메인은 전체 공개한다.
- `@` 앞 로컬 파트는 아이디 마스킹 기준과 동일하게 처리된 값을 표시한다.

## 탭 3: 비밀번호 재설정

### 화면 흐름

```text
이메일 입력
-> 인증코드 받기
-> 인증코드 입력
-> 인증하기
-> 새 비밀번호 입력
-> 비밀번호 재설정
```

### 1단계: 인증코드 발송

입력 필드:

```text
이메일
```

버튼:

```text
인증코드 받기
```

호출 API:

```http
POST /api/auth/send-password-reset-code
```

Request:

```json
{
  "email": "user@example.com"
}
```

성공 시 표시:

```text
인증코드를 이메일로 발송했습니다.
```

### 2단계: 인증코드 확인

입력 필드:

```text
인증코드
```

버튼:

```text
인증하기
```

호출 API:

```http
POST /api/auth/verify-password-reset-code
```

Request:

```json
{
  "email": "user@example.com",
  "code": "123456"
}
```

성공 시 응답:

```json
{
  "message": "인증이 완료되었습니다.",
  "resetToken": "temporary-reset-token"
}
```

성공 후 새 비밀번호 입력 영역을 보여준다.

### 3단계: 새 비밀번호 재설정

입력 필드:

```text
새 비밀번호
새 비밀번호 확인
```

버튼:

```text
비밀번호 재설정
```

호출 API:

```http
POST /api/auth/reset-password
```

Request:

```json
{
  "email": "user@example.com",
  "resetToken": "temporary-reset-token",
  "newPassword": "Newpass123!"
}
```

성공 시 표시:

```text
비밀번호가 재설정되었습니다.
```

성공 후 처리:

- 로그인 화면으로 돌아가게 한다.
- 또는 로그인 버튼을 강조해서 사용자가 바로 로그인할 수 있게 한다.

## 프론트 상태 관리 체크리스트

- 아이디 찾기 이메일 값이 바뀌면 마스킹된 아이디, 인증코드, 전체 아이디 상태를 초기화한다.
- 아이디 찾기 인증코드가 틀리면 인증코드 입력창 아래에 메시지를 표시한다.
- 이메일 찾기 아이디 값이 바뀌면 마스킹된 이메일 상태를 초기화한다.
- 비밀번호 재설정 이메일 값이 바뀌면 인증코드, resetToken, 새 비밀번호 입력 상태를 초기화한다.
- 비밀번호 재설정 인증 성공 전에는 새 비밀번호 입력 영역을 보여주지 않는다.
- API 요청 중 중복 클릭을 막는다.
- 서버 오류가 발생하면 `"잠시 후 다시 시도해 주세요."`를 표시한다.

## 발표자료용 한 줄

계정 찾기와 비밀번호 재설정 기능은 개인정보 보호를 위해 인증 전에는 아이디와 이메일을 마스킹하여 제공하고, 이메일 인증이 완료된 경우에만 전체 아이디 확인 또는 비밀번호 재설정이 가능하도록 예외처리 기준을 정리했습니다.
